# リリースノート

各バージョンの追加・改善・修正です。gtree をお使いの場合、新しいバージョンが出るとサイドバー下部に「更新して再起動」が表示されます。

## v0.3.9 (2026-10-10) — Codex に対応、エージェント同士で相談、「チームメンバー」を追加

### 新機能
- Codex に対応しました。設定で「Codex をつなぐ」をクリックすると、Codex のセッションも Claude Code と同じように扱えます。何をしているか、いつあなたを待っているかがひと目でわかり、待っているものは「対応待ち」に並び、ターンごとの変更も記録されてロールバックできます。Codex 側で一つずつ承認する必要はありません。
- AI ビューの「+」から Codex を新しく開き、内蔵ターミナルで Claude Code と並べて動かせます。「履歴」でも Codex の会話を検索・再生できます。
- 同じ worktree で動くエージェント(Claude Code でも Codex でも)が互いを把握するようになりました。一方が、もう一方も変更したファイルを変更すると相手に自動で知らせ、同じ箇所を変更する前には伝言を残してどちらが先に進めるかを相談します。先に終えた側は相手に知らせます。
- 「チームメンバー」を追加しました(初期設定はオフ、リポジトリごとにオン)。最近ほかの人がコミットしているリポジトリでは、サイドバーのプロジェクトの下に「チームメンバー」が表示されます。「オンにする」→「共有を始める」で、チーム自身の git リポジトリを通じて、未コミットの変更も含めた作業中のコードをメンバーと見せ合えます。ブランチをクリックすると相手の変更を確認できます。
- チームメンバーと同じ箇所を変更しそうなとき、あなたの AI は編集する前に手を止めてあなたに確認します。「対応待ち」にも表示され、「相手の変更を見る」ですぐ確認できます。
- AI からチームメンバーに伝言を残せます。相手本人が読んで「自分の AI に渡す」をクリックしたときだけ相手の AI に届き、返事は尋ねた AI に自動で戻ります。
- チームメンバー間のやり取りはすべて署名され、伝言は受け取る本人しか読めません。リポジトリにアクセスできるほかの人がメンバーになりすますことはできません。メンバーの身元が変わったときは、本人だと確認するまで何も受け取りません。

### 改善
- ステータスバーの「別のターミナルで AI が開いています」をクリックすると、セッションの一覧が開きます。何を尋ねたか、どれくらい前か、何をしているかが並び、クリックで該当のターミナルへ切り替えます。開いている場所がわからないものは、その会話を再生します。
- ファイルツリーの右クリックから「ブラウザで開く」「既定のアプリで開く」「Finder で表示」「ターミナルで開く」(gtree の内蔵ターミナル)「パスをコピー」が使えます。

### 修正
- ガイドのページをめくるときに別の画面が一瞬映る問題を修正しました。最後のページの動画は「Claude Code に接続」する手順に差し替えました。
- 同じ worktree で長いコマンドを並行して実行したとき、ファイルが別のセッションのものとして扱われる問題を修正しました。テスト出力の「0 failed」もエラーと見なさなくなりました。
- Claude Code の接続説明から、アプリが実際には表示しない「エラー」「停止」の状態についての記述を削除しました。

## v0.3.8 (2026-10-09) — 「対応待ち」と通知を追加、ナビを 4 項目に整理

![gtree の「対応待ち」画面。上にあなたを待っているセッションが「開く →」付きで並び、「気にかけておくと良いもの」に同じファイルを変更している worktree が、いちばん下に「作業中」の AI が表示されている](/media/app/inbox-ja-light.webp "新しい最初の画面「対応待ち」。誰があなたを待っているか、どこで作業が重なっているかが 1 ページでわかります")

### 新機能
- 最初の画面が「対応待ち」になりました。今あなたが対応すべきことがあるかだけを伝えます。あなたを待っている AI を待ち時間の長い順に先頭に並べ、続いて 2 つのブランチが同じファイルを変更しているなど、気にかけておくと良いことを表示します。
- AI が止まってあなたを待っているとき(許可が必要なとき、またはターンを終えて返事を待っているとき)、macOS の通知でお知らせし、クリックでそのセッションへ移動できます。Dock アイコンには待っている件数が表示されます。
- 同じ worktree で 2 つの Claude Code セッションが作業しているとき、もう一方が変更したばかりのファイルを編集する前に AI へ知らせ、互いに上書きしないようにします。
- 設定から gtree をこの Mac から削除できます。Claude Code との接続を解除し、gtree のデータを削除して(再インストール予定なら残すこともできます)、アプリをゴミ箱へ移します。

### 改善
- ナビゲーションを 7 項目から 4 項目(対応待ち・ワークベンチ・変更・AI)に整理し、⌘1–⌘4 で順に開けます。「変更」には AI の変更・コミット履歴・比較をまとめました。
- Claude Code への接続は、ガイド・ワークベンチのお知らせバー・空の「AI の変更」画面からワンクリックで行えます。通知の許可も同時に確認するので、ターミナルでのコマンド入力は不要です。
- 「比較」を開くと、メインブランチと現在の worktree の差分が最初から表示されます。

### 修正
- 数百のブランチがあるリポジトリで、Mac 全体が重くなる問題を修正しました。
- ターミナルタブを閉じると、中で動いている Claude も終了するようになりました。同じ worktree で複数の Claude タブを開いても、状態が互いに上書きされなくなりました。
- ダウンロードフォルダから直接開いた gtree で、アップデートや Claude Code への接続が失敗する問題を修正しました。アプリケーションフォルダへの移動もワンクリックで行えます。

## v0.3.7 (2026-10-09) — gtree をどこに移動しても Claude Code 連携はそのまま

- gtree.app を別のフォルダへ移動しても、Claude Code との接続が知らないうちに切れることはなくなりました。接続済みの場合は、初回起動時に自動で切り替わります。

### 修正
- 一部のターミナルでインストールコマンドが「unbound variable」で失敗する問題を修正しました。0.3.3 以降、多くの方がこのエラーでインストールできていませんでした。

- 新しくインストールした方が、匿名の利用統計にインストール当日から正しく反映されるようになりました。これまでどおりお知らせを表示した後にのみ集計し、設定からオフにできます。

## v0.3.5 (2026-10-09) — ブラウザでダウンロードしても確実に起動

## v0.3.3 (2026-10-09) — Claude Code 連携を設定画面から導入

![gtree の設定の「Claude Code との接続」欄。「未接続」の表示と「Claude Code に接続」ボタン、接続すると何ができるかの説明がある](/media/app/settings-claude-not-connected-ja-light.webp "設定からワンクリックで Claude Code に接続できます。何ができて何が変わるかも、その場で説明しています")

### 新機能
- 設定に「Claude Code 連携」を追加しました。ワンクリックで導入でき、何のために入れるのか、何が変わるのかを平易に説明します。インストール先の変更、hook ごとの確認とオン・オフ、アンインストールもここで行えます。
- Claude Code 連携が未導入または更新が必要なとき、ワークベンチにお知らせバーを表示し、設定へ直接移動できます。
- AI タブをドラッグで並べ替えられるようになりました。タブが多いときはタブバーをスクロールできます。
- 設定で、近日公開予定のチームプランの概要と予定価格をご案内し、アーリーバード登録もできるようにしました。

### 改善
- タイムラインの冒頭に用途の説明を加え、既定ではファイルを変更したターンだけを表示するようにしました。システムメッセージや Markdown も読みやすく表示します。
- サイドバー、ファイルパネル、AI の履歴パネルの開閉をなめらかなアニメーションにしました。
- コマンドラインの出力と `gtree --help` が表示言語に合わせて表示されます。

### 修正
- サイドバーの開閉中に、内容がウィンドウのボタンに重なる問題を修正しました。
- Claude Code のサブエージェントが終了した後も、過去の会話が「別のターミナルで開いています」のままになり再開できない問題を修正しました。

## v0.3.0 (2026-10-08) — タイムライン:AI のターンごとに見返して復元

![「AI の変更」画面。中央にファイルを変更したターンが並び、右側に選択したターンの質問、Claude の返答、変更されたファイルと diff、右上に「このターンに復元」がある](/media/app/ai-changes-timeline-ja-light.webp "ターンごとの質問・返答・変更が残り、「このターンに復元」でそのターンのファイルを戻せます")

### 新機能
- 「スナップショット」は「タイムライン」になりました。Claude Code のターンが終わるたびに質問・返答・変更されたファイルを記録し、ターンごとの差分を確認したり、そのターンで変更されたファイルを元に戻したりできます。ブランチやステージングエリアには触れません。
- 新しい Claude Code セッションは、同じ worktree で前のセッションがどこまで進んだか(質問、最後の返答、変更したファイル)を把握した状態で始まります。
- AI が自分で過去のターンの記録を調べられるようになりました。ほかのプロジェクトの記録も対象です。
- コミットグラフに、AI の各ターン終了時の状態を、現在のコミットから伸びるブランチのように表示できます。ツールバーで表示を切り替えられます。
- コラボ画面の先頭に、動いている AI ごとのカードが並びます。何をしているか、前のターンで何をしたかがわかり、あなたを待っている AI が先頭に来ます。
- 「見に行く」で、worktree で作業中の Claude へ直接移動できます。gtree 内なら AI タブへ、ご自身のターミナルで動いている場合は読み取り専用の再生を開きます。

### 改善
- ダウンロードとアップデートは gtree 専用のダウンロードサーバーを経由し、つながらない場合は自動で GitHub に切り替えます。
- 匿名の利用統計を導入しました。送信を始める前に初回起動時にお知らせし、お知らせから、または GTREE_NO_TELEMETRY=1 でオフにできます。
