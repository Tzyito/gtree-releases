gtree をつくっている人

tzyito個人開発者 · gtree 作者

こんにちは、tzyito です 👋 毎日いくつものエージェントを同時に動かしていて、どれが自分を待っているのかターミナルを行き来して探すのに疲れ、gtree をつくりました。

いまは毎日、gtree そのものを gtree で開発しています。

安心して使える理由

  • gtree はコードをアップロードしません

    gtree はあなたの Mac 上でだけリポジトリを読み書きします。アカウントもクラウド同期もなく、あなたのコード・会話・ファイルパスを gtree が私たちに送ることはありません。

  • リポジトリの変更は、あなた自身の git で

    コミット、プッシュ、リベースは Mac 上の git が実行します。認証情報、SSH key、hooks はそのまま使え、設定し直す必要はありません。

  • 匿名の利用統計はオフにできます

    集計するのは利用者数と使用バージョンだけで、個人は特定できません。初回起動時にお知らせし、設定からいつでもオフにできます。

気になりそうなこと。

  • 個人版に機能制限はありません。Mac 上だけで動く機能 —— ワークスペースとエージェントの状態、タイムラインでのロールバック、会話履歴の検索、任意の 2 点間の Diff、衝突の事前警告、ローカルのコラボビュー —— はずっと無料で、今後有料に変わることもありません。有料になるのは、サーバーが必要なチーム機能だけです。

  • チームプランは開発中のため、現時点で具体的な日付はお約束できません。完成したら、まずアーリーバードの登録者にお知らせします。登録者はリリース後の初年度が 50% オフになります(予定価格は $12/人/月、年払いなら $10/人/月)。登録は無料で、何の義務も発生しません。

  • gtree はアップロードしません。Mac 上でだけリポジトリを読み書きし、コード・会話の内容・ファイルパスを私たちに送ることはありません。AI との会話は、あなた自身の Claude Code や Codex が Anthropic や OpenAI に送り、それぞれの規約に沿って扱われます —— gtree を使わない場合と同じです。リポジトリで「チームメンバー」をオンにすると、作業中の変更はチーム自身の git リポジトリに送られます。こちらも私たちを経由しません。チームプランも同じ原則で設計しています:コードは私たちのサーバーを経由しません。

  • はい。会話履歴の検索と続きからの再開、ターンごとのタイムラインとターン単位の復元、任意の 2 点間の Diff は、エージェントが 1 つでも同じように便利です。2 つ目を同時に動かしたくなったときには、もう準備ができています。

  • ターミナルや tmux が管理するのはウィンドウで、中のエージェントが何をしているかは知りません。gtree は各エージェントが実行中か、承認待ちか、待機中かを見分け、長く動きがないときも知らせます。通知するのは、あなたが必要なときだけです。さらに各エージェントがどのファイルを変更したかも把握しているので、2 つが同じファイルを編集しそうなら事前にお知らせします。ターミナルももちろんあります —— worktree ごとに 1 つ、中で動いているのは claude や codex そのものです。

  • 現在は macOS の Apple Silicon 版のみです。Intel Mac、Windows、Linux への対応は計画中ですが、具体的な時期は未定です。

$curl -fsSL https://gtree.dobbylab.com/install.sh | bash
  1. 「ターミナル」を開き、上の 1 行を貼り付けて Return を押します。
  2. 「アプリケーション」にインストールされ、終わると自動で起動します。
  3. 新しいバージョンが出ると、サイドバー下部に「アップデートして再起動」が表示されます。クリックするだけで、再インストールは不要です。

zip を直接ダウンロード初回は「開発元を検証できません」と表示されます。「完了」を押し、「システム設定 → プライバシーとセキュリティ」の下部で「このまま開く」を押してください。上のコマンドで入れればこの手順は不要です。
