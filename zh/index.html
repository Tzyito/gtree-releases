谁在做 gtree

tzyito独立开发者 · gtree 作者

嗨,我是 tzyito 👋 我每天同时开好几个 Agent,受够了来回切终端找谁在等我,就做了 gtree。

现在我每天用 gtree 开发 gtree 本身。

为什么信得过

  • gtree 不上传你的代码

    gtree 只在你的电脑上读写仓库。没有账号,不往云端同步,gtree 不会把你的代码、对话和文件路径传给我们。

  • 改仓库走的是你自己的 git

    提交、推送、变基都交给你电脑上的 git 执行:凭证、SSH key、hooks 照常生效,什么都不用重新配。

  • 匿名统计可以关

    只匿名统计有多少人在用、用的是哪个版本,对应不到你本人;第一次打开时会告诉你,随时可以在设置里关掉。

常见问题

你可能想问的。

  • 个人版没有功能限制。所有只在你电脑上跑的功能 —— 工作台和 Agent 状态、时间线回滚、历史对话搜索、任意两端 Diff、撞车预警、本机协作视图 —— 永久免费,以后也不会改成收费。要收费的只有需要服务器的团队功能。

  • 团队版还在开发,现在不承诺具体日期,做好了会先通知早鸟名单。名单上的人上线后首年 5 折(预计 $12/人/月,年付 $10/人/月)。加入名单不用付钱,也不绑定任何东西。

  • gtree 不会上传。它只在你的电脑上读写仓库,不会把你的代码、对话内容和文件路径传给我们。和 AI 的对话由你自己的 Claude Code 或 Codex 发给 Anthropic 或 OpenAI,按各自的条款处理 —— 这部分和不用 gtree 时一样。打开了「队友」的仓库,还在写的代码会推到你们团队自己的 git 仓库,同样不经过我们。团队版也按同一条原则设计:代码不经过我们的服务器。

  • 有。历史对话搜索和接着聊、每一轮改动的时间线和按轮恢复、任意两端的 Diff,只开一个 Agent 时同样好用。等你哪天想同时开第二个,它已经在那了。

  • 终端和 tmux 管的是窗口,不知道里面的 Agent 在干什么。gtree 认得出每个 Agent 是在跑、在等你授权还是已经空闲,很久没动静也会提醒你,只在需要你时打扰你;它还知道每个 Agent 改了哪些文件,两个改到同一个文件会提前告诉你。终端也还在 —— 每个工作副本一个,里面跑的就是 claude 或 codex 本身。

  • 支持 Claude Code 和 Codex,更多 Agent 陆续接入。想要哪个,可以写信告诉我们。

  • 能。所有改仓库的操作(提交、推送、拉取、变基、合并…)都交给你电脑上的 git 执行,完整继承你已经配好的凭证、SSH key、pre-commit hooks 等。

  • 不会收集你的代码、文件、仓库信息和对话内容。我们只匿名统计有多少人在用、用的是哪个版本,不能对应到你本人。第一次打开时会告诉你,随时可以在设置里关掉。

  • 目前只有 macOS 的 Apple Silicon 版本。Intel Mac、Windows 和 Linux 在计划里,还没有具体日期。
