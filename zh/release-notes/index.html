版本说明

每个版本新增、改进和修复了什么。已经装了 gtree 的话,有新版本时侧栏底部会提示「更新并重启」。

v0.3.9最新

2026年10月10日 · 连上 Codex,agent 之间自己商量,新增「队友」

新增#

  • 连上 Codex:在设置里点「连上 Codex」,Codex 会话就和 Claude Code 一样 —— 在干什么、什么时候在等你一眼看清,在等你的进「待处理」,每一轮的改动都记下来、可以按轮恢复,不用再去 Codex 里逐条批准。
  • AI 视图的「+」可以新开 Codex,和 Claude Code 并排跑在内嵌终端里;「历史对话」也能搜到、回放 Codex 的会话。
  • 同一个工作区里的 agent(Claude Code 或 Codex)互相知道对方:一个改了另一个也改过的文件,对方会自动收到通知;要改同一处时会给对方留话、商量谁先改,先改的一方做完会告诉另一方。
  • 新增「队友」,默认关、按仓库开:最近有别人提交的仓库,侧栏项目下会出现「队友」一节,点「开启」、再点「开始同步」后,你和队友经团队自己的 git 仓库互相看到还在写的代码(包括没提交的),点开就能看对方的改动。
  • 和队友改到同一处时,你的 AI 会在动手前先停下来问你;「待处理」里也会提醒,点「看对方的改动」直接看。
  • AI 可以给队友留话:对方本人看过、点「交给我的 AI」后才会交给他的 AI,回复会自动回到发问的那个 AI。
  • 队友之间的内容都带签名,留言只有收件人能解开,仓库里的其他人冒充不了队友;队友的身份变了,要你确认是本人才继续接收。

改进#

  • 状态栏的「别处开着的 AI」点开是一份会话列表:问的什么、多久前、在干什么,点一行就切到对应的终端;认不出在哪的,打开这段对话的回放。
  • 文件树右键可以在浏览器中打开、用默认程序打开、在 Finder 中显示、在终端中打开(在 gtree 的内嵌终端里)和复制路径。

修复#

  • 引导翻页时不再闪出别的画面;最后一页的动图换成了「连上 Claude Code」的演示。
  • 同一个工作区并行跑长命令时,文件不再被算到别的会话名下;测试输出里的「0 failed」也不再被当成报错。
  • Claude Code 的连接说明里,去掉了应用实际不会显示的「出错 / 卡住」状态。

v0.3.8

2026年10月9日 · 新增「待处理」和系统通知,导航收成 4 项

新增#

  • 「待处理」成为第一屏,只回答一件事:现在有没有要你处理的。在等你的 AI 按等了多久排在最前,下面是也许要留意的事,比如两条分支改了同一个文件。
  • AI 停下来等你(要授权,或者答完一轮在等你回复)时,发一条 macOS 系统通知,点一下跳到那个会话;Dock 图标上显示有几件事在等你。
  • 同一个 worktree 里开着两个 Claude Code 会话时,一个 AI 要改另一个刚改过的文件前会先收到提醒,不会互相覆盖。
  • 设置里可以直接从这台 Mac 删除 gtree:断开 Claude Code、删掉 gtree 的数据(打算重装也可以保留),再把 app 移到废纸篓。

改进#

  • 导航从 7 项收成 4 项:待处理 / 工作台 / 改动 / AI,⌘1–⌘4 依次对应;「改动」里分成 AI 改动、提交历史、对比。
  • 连上 Claude Code 只要点一下:引导最后一页、工作台提示条、空的「AI 改动」页都能直接连,通知权限一并询问,不用再去终端敲命令。
  • 打开「对比」就有内容:默认是主分支 → 当前 worktree。

修复#

  • 几百个分支的仓库不再把整台 Mac 拖慢。
  • 关掉终端标签时,里面的 Claude 会一起结束;同一个 worktree 开多个 Claude 标签时,状态不再互相覆盖。
  • 从「下载」文件夹直接打开 gtree 时,更新和连上 Claude Code 不再失败,还能一键把它移到「应用程序」。

v0.3.7

2026年10月9日 · gtree 放在哪都行,Claude Code 集成不会失效

改进#

  • 把 gtree.app 挪到别的文件夹后,和 Claude Code 的连接不会再悄悄断掉;已经连上的,首次启动时自动切换过来。

修复#

  • 安装命令在部分终端里报「unbound variable」、装不上的问题修好了;0.3.3 起很多新用户因此没装成。

v0.3.6

2026年10月9日 · 新用户安装当天就能正确计入使用统计

修复#

  • 新安装的用户当天就能被匿名使用统计正确计入;仍然是先告知、后统计,可以在设置里关闭。

v0.3.5

2026年10月9日 · 浏览器下载的安装包也能顺利打开

修复#

  • 浏览器下载的 zip 打开时不再提示「gtree 已损坏,无法打开」:安装包已完整签名,首次打开只需在「系统设置 → 隐私与安全性」里点「仍要打开」。

v0.3.3

2026年10月9日 · 在设置里一键接入 Claude Code

新增#

  • 设置里新增 Claude Code 集成:一键安装,用大白话讲清为什么要装、会改动什么;还能改安装位置、逐条查看和开关 hook,或者卸载。
  • Claude Code 集成没装或需要更新时,工作台顶部出现提示条,点一下直达设置。
  • AI 标签可以拖动排序,标签多了放不下时可以横向滚动。
  • 设置里预告了即将推出的团队版:说明、预计价格和早鸟名单入口。

改进#

  • 时间线顶部用一句话说明用途,默认只列改了文件的轮次,系统消息和 Markdown 都显示成好读的文字。
  • 侧栏、文件面板、AI 历史栏的开合改成顺滑的动画。
  • 命令行输出和 gtree --help 跟随界面语言。

修复#

  • 侧栏开合过程中,内容不再压到窗口左上角的按钮上。
  • Claude Code 子 agent 结束后,历史对话不再一直显示「正开在别的终端里」,可以正常接着聊。

v0.3.2

2026年10月9日 · 界面支持英文和日文,新增首次启动引导

新增#

  • 界面支持英文、日文和简体中文,默认跟随 macOS 语言,也可以在设置里切换,立即生效。
  • 侧栏左下角新增齿轮按钮,点开就是设置,上面标着当前语言。
  • 新用户第一次启动会看到 6 页的新手引导,之后随时可以在「设置 → 通用」里重新查看。

改进#

  • 打开了 macOS「减弱动态效果」时,新手引导只做淡入淡出。
  • 安装命令的终端输出改成英文。

修复#

  • 英文、日文界面下工作台面板标题不再被截断。
  • 协作视图的卡片不再把系统标签当成你的提问显示出来。

v0.3.1

2026年10月8日 · 新增设置面板,随时开关匿名使用统计

新增#

  • 新增「设置」(⌘,,或菜单栏 gtree → 设置…),第一项就是匿名使用统计的开关,随时可以打开或关闭。

改进#

  • 首次启动时的统计说明改成大白话,并告诉你可以在设置里关掉。

v0.3.0

2026年10月8日 · 时间线:AI 每一轮的改动都能回看、能恢复

新增#

  • 「快照」改成「时间线」:Claude Code 每答完一轮,gtree 记下你的提问、它的回复和改了哪些文件,可以逐轮看 diff,把那一轮动过的文件恢复回去,不碰分支和暂存区。
  • 新开的 Claude Code 会话一开头就知道同一个 worktree 里上一个会话做到哪:问了什么、最后说了什么、改了哪些文件。
  • AI 自己就能翻以前几轮的记录,其他项目的也能查。
  • 提交图上可以显示 AI 每一轮结束时的样子,像一条从当前提交长出来的分支,用工具条上的开关显示或隐藏。
  • 协作视图顶部给每个在干活的 AI 一张卡片,写着它在做什么、上一轮做到哪,在等你的排在最前。
  • 「去看看」直接跳到某个 worktree 里正在干活的 Claude:开在 gtree 里的切到它的 AI 标签,跑在你自己终端里的打开只读回放。

改进#

  • 下载和更新改走 gtree 自己的下载服务器,连不上时自动改连 GitHub。
  • 新增匿名使用统计,第一次启动时先告知再上报;可以在告知卡片里关掉,或设置 GTREE_NO_TELEMETRY=1。
