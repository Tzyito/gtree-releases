# gtree releases

gtree(Git worktree 图形工具)的 macOS 安装包与自动更新源。源码不在这里。

## 安装(Apple Silicon)

```bash
curl -fsSL https://github.com/Tzyito/gtree-releases/releases/latest/download/install.sh | bash
```

装到 `~/Applications/gtree.app`。之后有新版本时,gtree 会在侧栏底部提示「更新并重启」,不用再跑这条命令。

请用上面的命令安装,不要从浏览器下载 zip —— 浏览器下载的 app 会被 macOS 拦下(未签名)。
