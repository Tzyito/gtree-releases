Who’s building gtree

tzyitoIndie developer · maker of gtree

Hi, I’m tzyito 👋 I run several agents every day and got tired of flipping between terminals to find the one waiting on me — so I built gtree.

These days I build gtree with gtree.

Why you can trust it

  • gtree never uploads your code

    gtree reads and writes your repos only on your Mac. No account, no cloud sync — gtree never sends us your code, conversations or file paths.

  • Repo changes go through your own git

    Commits, pushes and rebases run through the git on your Mac, so your credentials, SSH keys and hooks just work. Nothing to reconfigure.

  • Anonymous stats you can switch off

    We only count, anonymously, how many people use gtree and which version — nothing that identifies you. You’re told on first launch and can switch it off in Settings any time.
